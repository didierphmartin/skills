# playbook-author

Turns a request typed in a conversation into a **Console-style playbook** and saves it as a **Playbook agent** (Agents list → *Playbooks*), which can be dragged onto a workflow canvas as a Playbook node.

Pipeline: model drafts JSON → `scripts/create.py` renders the canonical text, checks the action list and auto-binds actions against `references/mcp-catalog.md` (generated by the app at startup) → the model fixes what the report flags (max two rounds) → `save_playbook_agent` (browser client tool) creates the agent row.

- `references/syntax.md` — the syntax the app's `PlaybookDocument` parser accepts and the binding rule of `PlaybookAnalyzer`.
- `references/example-playbook-*.md` — the four playbooks from the workflow section, verbatim.
- `tests/` — `python3 -m unittest tests/test_create.py`
