A coordinated set of skills for end-to-end search optimization — from competitive
discovery and topic-cluster planning, through on-page audits, all the way to
post-publish SERP-shape and indexing verification.

These are designed to be **composable**: each skill produces structured output
the next one can consume, so a full SEO program can be assembled by chaining
them in any order that fits the team's workflow. The contained workflow link
below is one such chain — start there if you want a turnkey audit pipeline,
or pick individual skills if you only need a focused diagnostic.

---

## 🔍 Discovery & Planning

| Skill | What it does |
|---|---|
| **seo-plan** | Builds a multi-quarter SEO roadmap from a domain + business goals. Outputs prioritized actions, target keywords, and milestone metrics. |
| **seo-competitor-pages** | Identifies the top-ranking competitors for a given keyword set and extracts the pages that drive their traffic. |
| **topic-cluster** | Maps a seed topic to a hub-and-spoke content cluster — pillar page + supporting articles, with internal-linking suggestions. |
| **seo-content-brief** | Generates a writer-ready content brief for one target keyword: SERP shape, intent, entities, headers, FAQ candidates. |

## 🩺 Audits

| Skill | What it does |
|---|---|
| **seo-audit** | Full on-page + technical audit for one URL: meta tags, headings, schema, internal links, Core Web Vitals signals. |
| **ai-search-audit** | Specialized audit for visibility in AI answer engines (Perplexity, Google AI Overviews, ChatGPT search). |
| **hreflang-audit** | Validates hreflang annotations across an international site — coverage, reciprocity, language/region pairing. |
| **image-audit** | Walks image assets and reports missing alt text, oversized files, inadequate `srcset`, and missing `loading="lazy"`. |
| **sitemap-audit** | Crawls the sitemap, verifies every URL returns 200, and cross-checks against canonical / robots / noindex signals. |

## 🚀 Post-publish

| Skill | What it does |
|---|---|
| **serp-shape** | Captures the live SERP for a target query: organic, AI Overview, People-Also-Ask, featured snippet, video carousel. |
| **seo-sxo** | Search Experience Optimization — measures bounce, scroll-depth, and conversion signals against ranking. |
| **seo-programmatic** | Template-driven generation of long-tail landing pages from a structured data source. |
